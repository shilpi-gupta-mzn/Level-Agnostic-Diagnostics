# Level-Agnostic Diagnostics for OntoUML and MLT

The separate files are supplied for inspection and traceability:

* `Violation_Seeded_Model.hutn` and `.dl` show the same model structurally and relationally.
* `LML_Profile.hutn` and `.dl` show the full LML profile structurally and as ordinary Datalog.
* `OntoUML_Profile.hutn` and `.dl` show the full OntoUML profile structurally and as ordinary Datalog.
* `MLT_Profile.hutn` and `.dl` show the full OntoUML profile structurally and as ordinary Datalog.
* `Program.dl` in the root of the project is a single fixture-specific Nemo program containing the complete model fact view.
* The result folder shows all the expected generated outputs.
